## Adatbázis információk

* Az adatbázis a dump fájl XAMPP-ba történő importálása után érhető el.
* A rendszer előre létrehozott tesztadatokat tartalmaz a könnyebb kipróbálás érdekében.

### Alapértelmezett Admin fiók
A rendszerbe az alábbi adatokkal tudsz belépni adminisztrátorként:
* **Felhasználónév:** `admin`
* **Jelszó:** `Qwertz1212??`

### Tartalom
Az adatbázis az alaphelyzetben tartalmazza:
* 3 darab étterem adatait.
* Kategóriákba rendezett termékeket.
* Néhány tesztfelhasználót és a hozzájuk kapcsolódó rendelési előzményeket.
* Séf ajánlatokat.
